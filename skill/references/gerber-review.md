# PCB 交付：实际 Gerber 全层截图复查

PCB 新画、改线、挪器件、重铺铜后的交付都执行本节。逐层看图和 DRC / ERC / 网表核对共同构成验收；只生成图片、只看 3D 或只看顶底层均不算完成。

## 同一版本的生产文件

1. 确认目标工作区和具体 PCB；多板工程逐板处理，不能默认第一块。记下 `.epcb2` 的 SHA256 和实际铜层数。
2. 保存布局、重算铺铜，按项目规则查全板 DRC；开启悬空检查、严格质量项及实际电源最小线宽。原理图 ERC 和逐脚核对也须通过。存在故障时仍可导出诊断图片，但报告不能记为交付通过。
3. 用 `fab <具体.epcb2> --files -o <本轮新目录>` 导出。本轮检查对象是该压缩包内的全部文件；修改 PCB 后重导全套，不能拼接新旧层。

按实际导出清单逐项建立截图和核对记录：

公开包不附内部截图脚本。先用 `fab <具体.epcb2> --files -o <新目录>` 导出，保存 PCB 与 ZIP 的 SHA256，解开 ZIP 并逐文件确认与散文件一致；用独立 Gerber 查看器逐层截图。全部铜层按同一毫米原点与比例显示，再叠加钻孔复核。

局部范围用毫米坐标记录；问题位置、板边接口、密脚出线、过孔汇合和电源汇流处须有可辨认细线的局部图。建议至少80像素/mm，并按最细线宽提高分辨率。完整板图先确认全局，再逐层放大可疑区域；不能把低分辨率缩略图当作局部检查。

可使用独立 Gerber 查看器；记录工具版本、实际打开的文件、图层及观察范围。钻孔须与铜层按真实坐标对齐，不能仅凭截图存在判定通过。

## 必须实际查看的图

- **所有铜层**：顶层、每一个内层、底层独立全板图，不能用多层叠色图遮住内层走线。普通走线转弯不得有90°直角或锐角，采用45°倒角；核对项目确实启用 `corner_angle = 120` 和严格 `sharp_corner`，不能用只拦小于90°的阈值代替。重点找回头弯、无障碍绕远、不合格转弯、重复或多余铜线、细颈与粗细交替、焊盘出线、偏心孔及参考地切割；T形分支与焊盘/过孔内接点按真实连接另行复核，不能误删支路。
- **正反阻焊**：开窗是去掉阻焊的位置；核对焊盘覆盖、过孔盖油及意外露铜，不能把黑白图的开窗误当成阻焊实体。
- **正反锡膏**：核对贴装面、散热焊盘分窗、孔口避让及不贴装触点是否误开钢网。空层也须说明为何应为空。
- **正反丝印**：核对适用器件本体完整外框、1 脚及极性、焊盘避让，允许按项目隐藏位号，但不能连本体轮廓和方向标记一起省略。
- **板框及全部钻孔文件**：核对外形、开槽、邮票孔和钻孔直径、孔心、焊环；用铜层与孔位叠加图找孔落在普通焊盘内、偏离走线等问题。盲埋孔按各钻孔文件的实际层跨度核对；总孔位图仅帮助定位，不表示每个孔都穿过所有铜层。
- **其他实际导出层及附件**：FPC 覆盖膜、补强等 Gerber 不能漏看；下单 JSON / 说明文件按本工程材料和面别核对。未知文件不得直接跳过。

各 Gerber 图保持从顶面看的共同坐标，底层也不镜像。为了装配观察另做的背面图须明确标注，不拿镜像装配图量跨层孔位。3D 正反面和装配截图用于补充检查外观及净空，不能替代内层和制造层。

## 发现问题后闭环

实际打开各层全图、相关局部图和钻孔叠加图，索引图不能代替逐张查看。建立逐文件的核对表，初始全部待查；查看后填写结论、问题的层 / 毫米坐标及对应网络或器件。未查看、渲染失败、未知层或未核实的空层继续保留待查，不能自动标通过。

Gerber 可能不带网络名；从原生工程用 `pads`、单层 `render --layer ... --window ...` 和检查报告定位网络，不能凭颜色猜网。区分悬空线头与仍服务焊盘、测试点或另一层的真实分支。没有障碍却多拐的短回头即使低于 `detour_min` / `detour_ratio` 门槛也须复核；不能把“没有报警”解释成“已经查全”。

确认异常后用原生编辑功能修改，保留所有必要接点，重跑完整检查、保存布局，再导出、重新看受影响层及跨层连接。最后记录当前 PCB / 压缩包哈希、全部层清单和未解决项；再次核对这些哈希对应实际工作区。图像不能证明微小间距和电气功能正确；剩余问题不得在交付摘要中写成“全部通过”。
