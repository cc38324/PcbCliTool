# 设计文件（`easyedatool gen` 的输入）

TOML 或 JSON（扩展名 `.json` 按 JSON 读，别的按 TOML），结构一样。完整例子：`examples/mp157demo.toml`（STM32MP157，100 × 80 mm，四层）。
**写错字段名会报错**（不认识的字段一律拒绝），照报错改就行。

单位：板子上的坐标、尺寸都是**毫米、y 向上**；自建符号的引脚坐标是 EDA 原理图单位（10 mil）；封装里的焊盘和外形框用封装自己的 `unit`（默认毫米，可以选 mil）。

## 顶层

| 表 | 必须 | 内容 |
|---|---|---|
| `[project]` | 是 | 工程名等 |
| `[board]` | 是 | 板框 |
| `[[symbols]]` | 否 | 自建原理图符号 |
| `[[footprints]]` | 否 | 自建封装（标准名不用定义） |
| `[[blocks]]` | 是（至少一个） | 功能块（原理图分框、PCB 自动排位区）；每个器件的 `group` 都要指向一个块 |
| `[[parts]]` | 是 | 器件 |
| `[[pours]]` | 否 | 铺铜 |
| `[[regions]]` | 否 | 禁布区 |
| `[[texts]]` | 否 | 丝印字 |
| `[designators]` | 否 | PCB 位号字高、线宽 |
| `[schematic]` | 否 | 原理图排版方式、地和电源网络名单 |
| `[placement]` | 否 | 没给位置的器件怎么摆（默认按真实大小排整齐的行） |
| `[rules]` | 否 | 板子的默认设计规则（间距、线宽、过孔、孔距） |
| `[[reuse]]` | 否 | 照参考板摆器件、抄铜（原厂参考设计的核心区） |
| `[[swap]]` | 否 | 器件里可以互换的脚（连接器 GPIO）：摆好以后按最短总长重新分网络 |

## `[project]`

```toml
[project]
name = "Demo"                     # 工程名（文件夹里的 .eprj3 叫这个）
time = "2026-09-25 12:00:00"      # 可选：写死时间，同一份设计每次生成一模一样的文件；不给用当前时间
# schematic = "Schematic1"        # 可选：原理图名，默认 Schematic1
# sheet = "P1"                    # 可选：图页名，默认 P1
# pcb = "PCB1"                    # 可选：PCB 名，默认 PCB1
# owner = "32 位十六进制"          # 可选
# [project.ids]                   # 可选：固定文档 id（EDA 开着文件夹时重新生成，认得出是同一块板）
# board = "…" ; pcb = "…" ; schematic = "…" ; sheet = "…"
```

## `[board]`

```toml
[board]
outline = [[0, 0], [30, 0], [30, 20], [0, 20]]   # 板框多边形（毫米），至少 3 点，不用闭合
# layers = 4                  # 铜层数：2（默认）/ 4 / 6 / 8；内层是嘉立创的 15、16 …（从上往下）
# stackup = "JLC04161H-7628"  # 叠层：嘉立创标准叠层的名字（默认按层数 JLC04161H-7628 / JLC06161H-7628 / JLC08161H-7628）
```

多层板的内层铺铜在 `[[pours]]` 里写 `layer = 15`（内层 1）、`16`（内层 2）…；盖住大半块板的内层铺铜，`route` 当铺铜平面（不在上面布线，只让过孔穿过）。

## `[[symbols]]` 自建符号

两种写法二选一：

```toml
[[symbols]]
name = "LDO3"                  # 符号名，[[parts]] 的 sym 用它
designator = "U"               # 位号前缀（"U" 或 "U?"）
description = "3-pin LDO"
ic = true                      # 芯片 / 连接器：原理图上它的附件（阻容、LED…）用导线连到引脚，块里靠左竖排
left = [["3", "IN"], ["1", "GND"]]     # 左列引脚 [脚号, 名字]，从上往下，间距 10，连接点在 x = -50
right = [["2", "OUT"]]                  # 右列引脚，连接点在 x = +50
```

```toml
[[symbols]]
name = "MCU"
designator = "U"
pins = [["1", "VDD", -60, 20, 0], ["2", "PA0", 60, 20, 180]]   # [脚号, 名字, x, y, 方向]：0 = 引脚在左、朝右；180 = 在右、朝左
```

- 脚号是字符串，和封装焊盘号、`nets` 里的号要一致。
- 名字和脚号不同才显示名字；三个脚以上显示脚号（照 EDA 自己库的规矩）。
- 同名会报错，也不能和内置符号重名。

**内置符号**（直接用，不用定义）：

| 名字 | 脚 |
|---|---|
| `RES` | 1、2 |
| `CAP` | 1、2 |
| `IND` | 1、2 |
| `DIODE` | 1 = K（阴极）、2 = A（阳极） |
| `LED` | 1 = A（阳极）、2 = K（阴极）——和 DIODE 相反 |
| `TEST_POINT` | 1 |

## `[[footprints]]` 自建封装

三种来源，按这个顺序选：

1. **标准名**：器件的 `fp` 直接写，不用定义。`easyedatool footprint list` 列出全部，`easyedatool footprint SOIC-8` 看尺寸和写法。都是典型值（阻容、SMB、SOT-23、SOT-23-6 是 V1.1 板子上用过的立创库封装；SOIC、TSSOP、MSOP、SSOP 是 TI 的推荐焊盘图；LQFP 是 ST 的），用之前和数据手册对一下。同名的 `[[footprints]]` 会盖过标准名。
2. **按封装类型生成**（`package`）：只填数据手册推荐焊盘图上的数，焊盘坐标、编号、方向、丝印、1 脚标记都由工具算。
3. **手写每个焊盘**：连接器、模组这类不规则的。

### 按封装类型生成（`package`）

毫米。`span` 是两排**焊盘中心**之间的距离（手册常标外沿或内侧：中心距 = 外沿 − 焊盘长 = 内侧 + 焊盘长）；`pad_length` 是焊盘沿引脚方向（离开本体的方向）的长，`pad_width` 是横着的宽；`body` 是本体 [沿焊盘排的长, 横向的宽]。

| package | 用在 | 要给 | 可选 |
|---|---|---|---|
| `chip` | 两个焊盘的贴片件：阻容感、二极管、保险丝 | `span`（两焊盘中心距）、`pad_length`（沿器件方向）、`pad_width`、`body` | `mark = "1"`（或 `"2"`）在那个焊盘外侧画一道，标阴极 |
| `dual` | 两排：SOIC、SOP、TSSOP、MSOP、SSOP、DFN、SON | `pins`（偶数）、`pitch`、`span`、`pad_length`、`pad_width`、`body` | `ep = [x, y]` 底部散热焊盘（编号 pins+1）；`drill` + `pad`（焊盘直径）就是通孔 DIP |
| `quad` | 四边：QFN、QFP、LQFP | `pins`、`pitch`、`span`（一个数，或 `[左右两列, 上下两排]`）、`pad_length`、`pad_width`、`body` | `ep`；长方形的 `side_pins = [左右每边脚数, 上下每边脚数]` |
| `sot23` | SOT-23 / SOT-23-5 / SOT-23-6 | `pins`（3、5、6）、`pitch`、`span`、`pad_length`、`pad_width` | `body` |
| `sot223` | SOT-223 | `pitch`、`span`、`pad_length`、`pad_width`、`tab = [宽, 长]` | `body` |
| `header` | 排针、排母、DIP | `pins`、`pitch`、`drill`、`pad`（焊盘直径） | `rows`（1、2）、`row_pitch`、`order`（`zigzag` 默认：1、2 上下相对；`ccw`：像 DIP 逆时针） |

编号和方向（原点在本体中心，y 向上）：
- `dual`、`sot23`、`sot223`：焊盘排沿 x 方向，1 脚在左下，逆时针数（下排从左到右，上排从右到左）；1 脚旁边画一个圆点。
- `quad`：1 脚在左列最上面，逆时针（左列从上到下，下排从左到右，右列从下到上，上排从右到左）；左上角画圆点。
- `chip`：1 在左、2 在右。
- `header`：1 脚方焊盘，其余圆的。

例子（QFN-32，5 × 5，数据手册：脚距 0.5，焊盘 0.3 × 0.85，两排焊盘中心距 4.9，散热焊盘 3.5 × 3.5）：

```toml
[[footprints]]
name = "QFN32_5X5"
package = "quad"
pins = 32
pitch = 0.5
span = 4.9
pad_length = 0.85
pad_width = 0.3
body = [5.0, 5.0]
ep = [3.5, 3.5]          # 33 号焊盘：符号里也要有 33 脚（一般接 GND）
```

写完跑 `easyedatool footprint <设计文件> --name QFN32_5X5`，看量出来的「脚间距 0.5」「上下两排中心距 4.9」「左右两列中心距 4.9」对不对。

### 手写每个焊盘

```toml
[[footprints]]
name = "SOT23_3"
designator = "U"
description = "SOT-23"
unit = "mm"                    # 可选："mm"（默认）或 "mil"
pads = [
  ["1", -0.95, -1.0, 0.9, 1.1],           # 贴片矩形 [焊盘号, x, y, 宽, 高]，中心坐标
  ["2",  0.95, -1.0, 0.9, 1.1],
  ["3",  0.0,   1.0, 0.9, 1.1],
]
outline = [-1.5, -1.6, 3.0, 3.2]          # 外形 [x, y, 宽, 高]（左下角和尺寸），同时画成丝印框
```

- 通孔：`["1", 0, 0, 1.7, 1.7, 1.0]`，第 6 个数是圆孔孔径（金属化）；孔径不能大于铜皮。
- 原点放在本体中心，焊盘坐标是焊盘中心，y 向上，负数正常；尺寸和位置抄数据手册的推荐焊盘图。
- `outline` 是本体轮廓（也画成丝印框），不是焊盘范围：焊盘可以伸出去，但一般压着它；一个焊盘都不压着时 `gen` 会提示。
- 槽孔、铜皮偏移、非金属化孔这类用 `patch` 直接改焊盘记录（EDA 字段名、单位 mil）：`patch = { "11" = { plated = false } }`。要改的焊盘号必须存在。

**内置封装**（EDA 库里带的）：`R0603` `C0603` `LED0603` `R0402` `C0402` `L0402` `L0603`（两焊盘 1、2），`SMA`（1、2），`TP0.5`（1）。0402 是立创库的（C0402 / L0402：0.50 × 0.54 mm，中心距 0.84；R0402：0.566 × 0.54，中心距 0.866）。

### 手写的例子（学坐标怎么写；这两个其实都有标准名 `SOT-223`、`HDR-1x4-2.54`）

SOT-223（AMS1117 这类 LDO）：脚 1–3 一排、间距 2.3；对面一块大散热片（脚 4；AMS1117 的散热片是输出，和脚 2 同一网络，别的器件看数据手册）；两排中心距 6.3；本体 6.5 × 3.5。

```toml
[[footprints]]
name = "SOT223"
designator = "U"
description = "SOT-223：脚间距 2.3，两排中心距 6.3，本体 6.5 x 3.5"
pads = [
  ["1", -2.3, -3.15, 1.2, 2.0],   # 下排：脚 1、2、3（中心 y = -3.15）
  ["2",  0.0, -3.15, 1.2, 2.0],
  ["3",  2.3, -3.15, 1.2, 2.0],
  ["4",  0.0,  3.15, 3.6, 2.0],   # 上排：散热片（中心 y = +3.15，和下排相距 6.3）
]
outline = [-3.25, -1.75, 6.5, 3.5] # 本体，中心在原点（引脚伸得远，焊盘不压着它，gen 会提示，核对过就行）
```

`gen` 以后 `pads --part U1` 应该看到：脚 1、2、3 的 x 依次差 2.3，y 相同；脚 4 的 y 比它们大 6.3。

1 × 4 排针（2.54 间距，通孔 1.0，焊盘 1.7）：

```toml
[[footprints]]
name = "HDR1X4_2R54"
designator = "J"
description = "1x4 排针 2.54"
pads = [
  ["1", -3.81, 0, 1.7, 1.7, 1.0],
  ["2", -1.27, 0, 1.7, 1.7, 1.0],
  ["3",  1.27, 0, 1.7, 1.7, 1.0],
  ["4",  3.81, 0, 1.7, 1.7, 1.0],
]
outline = [-5.08, -1.27, 10.16, 2.54]   # 本体 10.16 x 2.54，中心在原点
```

## `[[blocks]]` 功能块

```toml
[[blocks]]
name = "PWR"                           # [[parts]] 的 group 用它
title = "5V in -> LDO 3V3 -> LED"      # 原理图上块框的标题
regions = [[13, 4, 28, 16]]            # 没给位置的器件在这些矩形 [x0, y0, x1, y1] 里自动排（毫米）
```

- 至少要有一个块，每个器件的 `group` 都要是某个块的 `name`。
- `regions` 只在块里有器件没给 `pcb` 位置时才用得上（全都给了位置可以不写）。区域画在板框里面，离板边留出器件本身的大小，不然排到边上的器件会伸出板外（`check` 会报）。
- 自动排（默认 `[placement] style = "tidy"`）：按每个器件的真实大小——焊盘和外形之间留 `spacing`（默认 0.5 mm），丝印框之间留 `silk_gap`（默认 0.2 mm）——在区域里像排字一样一行行摆：大封装在前，同封装同值的放一起、按位号排（C1 C2 … C10），同样的器件节距一样、列对齐，一行的器件在中线上对齐，行与行之间留出一行位号的高度，原点都在网格（默认 0.5 mm）上；位号放在每个器件正上方。器件给了 `cell` 就按 `cell` 的大小。
- `style = "shelf"` 是 KNXACBridge build.py 的老摆法（固定格子：标准名和 `package` 封装按实际大小外加 0.3 mm，手写封装 3.0 × 2.4 mm），核对 build.py 时用。
- 自动排的器件避开已经定了位置的器件（给了 `pcb` 的、`[[reuse]]` 照参考板摆的；通孔件两面都避）和 `[[reuse]]` 抄来的走线、过孔（同一面）：区域扣掉这些以后，剩下的空地切成最大的空矩形再排。
- 放不下会报「block X: no room left in its regions for R5」，前面一行写出这一面避开别的东西以后还剩哪些空位、合计多少 mm²、这些器件要多少：放大区域、多给几个区域，或给器件固定位置。

## `[[parts]]` 器件

```toml
[[parts]]
ref = "U1"                                 # 位号，不能重复
sym = "LDO3"                               # 符号（自建或内置）
fp = "SOT23_3"                             # 封装（自建或内置）
value = "AMS1117-3.3"                      # 值（BOM 的 Comment、原理图上显示）
nets = { 3 = "VIN", 1 = "GND", 2 = "+3V3" } # 脚号 = 网络名；没列的脚悬空
nc = [4]                                   # 可选：故意不接的脚，原理图上画非连接标识（×），erc 不报悬空
group = "PWR"                              # 所属功能块（必须写，必须是 [[blocks]] 里的 name）
pcb = [9, 10]                              # 可选：封装原点（自建封装的 (0, 0)）在板上的位置（毫米）；不给就自动排
angle = 90                                 # 可选：转角（度，逆时针）
side = "bottom"                            # 可选：装在背面（默认正面 top）
cell = [3.0, 2.4]                          # 可选：自动排位时占的格子（含丝印）；不给：标准名 / package 封装按实际大小，手写封装按 0603 大小

[[parts]]
ref = "U2"
lcsc = "C45843"                            # 用公司元件库里的件：立创编号（库里没有就先从立创拉进库）……
# part = "910119748"                       # ……或者料号 / 草稿文件夹名 / 厂家型号；这两种都不用写 sym、fp
value = ""                                 # 可选：给了就写进 Value、原理图上显示（阻容写 10k、100nF）；不给显示厂家型号
nets = { 16 = "+3V3", 15 = "GND", 11 = "UART_TX", 12 = "UART_RX" }
group = "IO"
```

- `nets` 里的脚号必须在符号上（否则报「no pin N on symbol」）；也必须在封装上，不然 `check` 会报逐脚差异。
- `nc`：数据手册写着 NC / DNC / 保留不接的脚、没用到的 IO、连接器空着的位，写进 `nc`，原理图上画嘉立创的非连接标识，`erc`（和嘉立创自己的检查）就不报「引脚悬空」。脚号要在符号上，不能同时写在 `nets` 里。没写进 `nets` 也没写进 `nc` 的脚照样悬空，`erc` 报出来：多半是漏接了。
- 有的器件给 `pcb`、有的不给（在块的区域里自动排）可以混用：一般芯片和连接器给位置，小阻容自动排。
- 网络名随便起，同名即相连。地叫 `GND` 这类、电源叫 `+3V3`、`VCC`、`VIN`、`3V3A` 这类，原理图上会自动画成地 / 电源符号（也可以在 `[schematic]` 里列名单）。
- 背面器件写 `side = "bottom"`：照嘉立创的规矩，封装先绕自己的 x 轴上下翻（y 变 −y），再按 `angle` 逆时针转（`angle` 就是嘉立创里这个器件的旋转角），位号写在底层丝印、镜像。BGA 底下的去耦电容、背面的连接器都这么放；背面器件可以放在正面器件正下方（`check` 的重叠、`drc` 的元件间距只比同一面）。没给 `pcb` 的背面器件在块的区域里另排一遍（和正面的各排各的，可以重叠）。`fab` 的贴片坐标里它们是 B 面。2026-10-03 用嘉立创自己的命令行打开核对过：12 个器件（8 个在背面，0° / 90° / 30°）的层、角度和每个焊盘的位置都和本工具读的一样（差 0.002 mm 以内）。
- `lcsc` / `part` 的件再写 `fp` 时用设计里的这个封装（自建的或标准名）代替元件库的，料号、厂家这些属性照样从元件库来：照参考板复用布局时保持参考板的焊盘大小。
- `lcsc` / `part`：找公司元件库的顺序同 `easyedatool lib`（环境变量 `EASYEDATOOL_LIB`、设计文件旁边的 `easyedatool.toml`、本机 `lib link` 配置）；器件属性自动写上 Manufacturer、Manufacturer Part、Supplier（LCSC）、Supplier Part（C 编号），`bom` 出来能直接交立创贴片。拉立创要联网，连着拉很多个会被嘉立创限流，报错就过几分钟再生成（拉过的都缓存了）。库里位号是 U 的件原理图上按芯片排（附件挂在脚上）；符号有几个单元的（SoC 分 DDR、GPIO、电源、地……）每个单元单独摆，`nets` 照样按脚号写全，gen 自己分到各单元。

## `[rules]` 设计规则

```toml
[rules]
clearance = 0.09      # 铜间距（mm）：安全间距表里走线、贴片 / 通孔焊盘、测试点、过孔、铜皮之间的格子（铺铜、板框、孔那几行不动）
track = 0.09          # 最细线宽
via = [0.4, 0.2]      # 最小过孔：外径、孔径
hole_to_hole = 0.25   # 孔边到孔边
pour = 0.15           # 铺铜到走线、焊盘、过孔、铜皮、别的铺铜（安全间距表的铺铜那一行；板框、孔那两格不动）
direct = ["NetL*_1", "5V_VIN"]   # 这些网络的铺铜直接连焊盘，不留热焊盘（* ? 通配）
```

写进工程的默认规则（嘉立创的 DRC 和 `easyedatool drc` 都按它查）；不写的项是嘉立创的默认（走线间 0.102、其余 0.152 mm，线宽 0.127，过孔 0.5 / 0.3，孔距 0.3，铺铜 0.254，焊盘接铺铜用热焊盘、间隙 0.254）。

- `pour`：参考板在 0.4 mm 脚距之间的小铜皮（PMIC 的开关节点）按嘉立创默认的 0.254 铺，会被吃光；照参考板的写（ST 的例子板 0.15）。
- `direct`：写成一条不带热焊盘的覆铜规则「direct」，再给每个网络挂一个规则选择器指向它（嘉立创自己存网络规则的写法），本工具铺铜时照它算。只比焊盘大一点的小铜皮（开关节点、电源岛）扣掉热焊盘的间隙就什么都不剩了，要直连。嘉立创 4 层以上板子能做到 3.5 mil（0.089 mm）线宽线距、0.15 mm 孔，复用细间距的参考板时照参考板的规则写。

## `[[reuse]]` 照参考板复用布局

```toml
[[reuse]]
from = "../build/st/board.PcbDoc"   # 参考板：嘉立创工程（文件夹 / .eprj3 / .epcb2）、Altium .PcbDoc、PADS .asc；相对路径从设计文件的文件夹算
parts = ["U1", "U2", "C1"]          # 照参考板摆的器件：参考板上的位号；["*"] = 设计里有、参考板上也有的全部
map = { "U5" = "U3" }               # 可选：参考位号 → 设计位号（不一样时）
move = [0, -26]                     # 参考板先绕自己的原点逆时针转 turn 度，再平移 move（mm）
turn = 0
copper = [[4, 46, 68, 99]]          # 可选：参考板这些矩形 [x0, y0, x1, y1] 里的铜抄过来（参考板自己的坐标）；不给不抄铜
skip_nets = ["eMMC*"]               # 可选：不抄铜的参考网络（* ? 通配）
tolerance = 0.25                    # 可选：器件焊盘和参考板的最多差多少（mm，默认 0.1），超了报错
stitching = false                   # 可选：false 时不抄孤立的缝合过孔（没有抄来的走线连着、不压在焊盘上、不在同网外层铜块里的），默认抄
copy_as = [{ rect = [4, 73, 24, 99], nets = { I2C4_SDA = "PMIC_SDA" } }]  # 可选：参考板的网络在这块里（参考板坐标）按设计的网络名抄，不管 skip_nets、local 和别处的焊盘（设计把参考网络拆开、只要其中一段时）
moves = [{ from = [36.4, 55.9], to = [35.6, 56.7] }]  # 可选：抄的时候挪参考板的铜（参考板坐标，差 0.01 mm 以内算同一点）：from 上的过孔不抄，走线在 from 的点挪到 to（把一个球的狗骨线改接到旁边同网球的过孔上，空出它原来过孔占的出线道）
local = [[4, 54, 68, 99]]           # 可选：给了就只有这些矩形里抄全部网络（芯片底下的扇出）……
routes = ["DDR_*", "SDMMC2_*"]      # ……这些参考网络在整个 copper 范围里抄；别的网络在 local 以外的线留给布线
```

- 列出的器件不用给 `pcb` / `angle` / `side`：每个器件按**焊盘号**拟合到参考板同位号器件的焊盘上（转角、平移按最小二乘算，背面器件先照嘉立创上下翻），面跟参考器件。封装来自别的库、原点不同、画的方向不同都没关系，焊盘号要一样（参考板上有、我们封装上没有的焊盘号不算，比如散热焊盘一边叫 ep 一边叫 45）。
- 参考网络按它在这些器件焊盘上对应的设计网络改名；焊盘在设计里不是同一个网络、或者是不接的脚的参考网络不抄，`gen` 输出里列出来；只连着没复用的器件的参考网络也不抄。
- 抄的铜：两头都在矩形里的走线段、矩形里的过孔（盲埋孔改成通孔）、铜皮（Altium / PADS 铺好的铜、嘉立创的铺铜轮廓和铜皮；裁到矩形里，写成比设计自己的铺铜优先的铺铜，gen 重新铺；设计在那层铺了同一个网络的不抄）。
- 封装的焊盘最好和参考板一样大（复用的器件写 `fp` 用照参考板焊盘画的封装，`package = "chip"`），不然参考板留的间隙会被大焊盘吃掉；`[rules]` 照参考板的规则写。
- `local` / `routes`：参考板在芯片四周绕的线挡住你自己的出线时（ST 的板子 MPU 一边绕着电源、I2C、地的线），只留芯片底下的扇出（`local`）和要整段照抄的几组线（`routes`：DDR、eMMC），其余重新布。
- 自动排位的器件避开复用器件和抄来的铜。布线用规则文件 `[nets] keep = ["*"]`：抄来的走线、过孔都留着，只补没连上的。

## `[[swap]]` 可以互换的脚

```toml
[[swap]]
part = "J11"                        # 器件位号
pins = [3, 5, 7, 8, 10, 11, 12]     # 这些脚上的网络可以互换（脚号；字符串或数字）
```

- 先在 `[[parts]]` 的 `nets` 里给这些脚随便写上网络（要接到排针上的那些信号）。器件全部摆好以后，`gen` 把这些网络在这组脚里重新分：每个网络到它别的焊盘（MCU 的球、上拉电阻）里最近那个的直线，整组加起来最短。这样分出来的直线两两不交叉，布线最顺。
- 原理图和 PCB 都照分好的写；`gen` 输出一行「J11 换脚：…个换了脚，直线总长 … → … mm：3=PE2 5=PC2 …」，就是排针定义。这组里没分到网络的脚写成不接（`nc`）。
- 用法：连接器的 GPIO（电源、地脚固定写在 `nets` 里、不放进 `pins`）、FPGA 同一 bank 里功能一样的 IO。MCU 那边的功能能不能换要自己定（用哪个球出哪个功能看芯片的复用表），这里只换连接器这一边。

## `[[pours]]` 铺铜

```toml
[[pours]]
net = "GND"
layer = 1                                                   # 1 顶层、2 底层
polygon = [[0.5, 0.5], [29.5, 0.5], [29.5, 19.5], [0.5, 19.5]]   # 多边形（自动写成 EDA 要的顺时针、闭合）

[[pours]]
net = "GND"
layer = 2
rect = [0.5, 0.5, 29, 19]                                   # 或矩形 [x, y, 宽, 高]（左下角和尺寸）
order = 2                                                   # 可选：优先级（嘉立创的 order，大的先铺、重叠处归它；默认 0）
```

`polygon` 和 `rect` 二选一。`gen` 默认照 EDA 的规则算好填充。`order`：两块铺铜重叠时大的先铺、占住重叠的地方；`[[reuse]]` 抄来的铜皮是 1（比设计自己默认的 0 先铺）。要在参考板的电源平面里挖出一块自己的电源（内层平面上给 WiFi 模块单独一块 3V3），写一块 `order = 2` 的铺铜盖上去。

## 成品板加丝印：`label` 命令的标注文件

布好线的板子不用重新生成就能加丝印字：`easyedatool label <工程> --from labels.toml [--write]`。只写 STRING 丝印字记录，铜皮和别的都不动；再跑一遍替换上次加的（记录 id 存在工程的 `.easyedatool/labels.json`）。

```toml
size = 1.0            # 字高（毫米），默认 1.0
min_size = 0.8        # 放不下时最小缩到多少，默认 0.8
rename = { "5V_VIN" = "5V", "I2C4_SCL" = "SCL" }   # 脚名默认用网络名，这里换成短名

[[part]]              # 器件旁边写它是干什么的
part = "J8"
text = "CAN"
# side = "auto"       # auto（默认，上、下、左、右第一个放得下的）/ up / down / left / right

[[pins]]              # 每个脚旁边写信号名
part = "J11"
size = 0.8
# min_size = 0.7      # 这个器件单独的最小字高（靠板边的排针）
# names = { "1" = "3V3" }   # 指定某个脚的字（默认网络名；没网络、Net 开头的不写）
# skip = ["40"]
# side = "auto"       # 默认朝器件外面：两排的排针每排各朝外，一排的朝板子里面

[[text]]              # 自由文字，放在给定位置（压东西会报出来，照放）
text = "MP157 DEMO V1.0"
at = [74, 48]
size = 1.2
# layer = 3           # 3 顶层丝印（默认）、4 底层丝印
```

- 字自己找地方：不压任何焊盘（离阻焊开窗 0.15 mm）、不压别的丝印字、不进任何器件的外框（装上器件就被盖住）、离板边 0.3 mm；从焊盘或器件边往外挪着找，放不下就缩小（不小于 `min_size`），一排的器件再试另一边，还不行就报「放不下」。
- 一排脚的名字横着并排放不下（比脚距宽）就整排竖起来写；排针靠板边那一列横着放不下也整列竖写——同一排 / 同一列朝向一致。

## `[placement]` 自动摆放

```toml
[placement]
style = "tidy"      # 默认：按真实大小排整齐的行；"shelf" = build.py 的固定格子
spacing = 0.5       # 焊盘和外形之间（毫米），默认 0.5；不小于 drc 的元件间距（默认 0.2）
silk_gap = 0.2      # 丝印框之间，默认 0.2
grid = 0.5          # 原点吸在这个网格上，默认 0.5
# row_gap = 0.9     # 行与行之间（默认留出一行位号：位号字高 + 0.6 − spacing）
tht_smd = 5.0       # 插件脚的焊接面（器件另一面）这么远内不自动放贴片件（过炉载具的最小要求），默认 5；0 不留
orient = true       # 没写 angle 的贴片件摆好后自动选 0/90/180/270 里飞线最短的方向（收发器的总线脚朝接口），默认关
near = true         # 没写 pcb 的小件（≤3 脚：终端电阻、上拉、去耦）不排行，就近放到要连的焊盘旁的空位，默认关
```

`near` 的目标是每个网络在已摆好的器件上最近的焊盘（多焊盘的电源 / 地、铺铜网络不算；两头都是电源 / 地的去耦电容靠最近那颗芯片的同名电源脚），从两者中间一圈圈往外找空位（不碰已摆的器件和它们的焊盘、抄来的铜、插件脚禁放区、板边），四个方向里挑飞线最短的；先 `orient` 定芯片方向，再 `near`。芯片定方向只看三脚以上的器件，旁边的两脚件跟着芯片走。行里排不下时（只开 `near`）先放到块中间再挪。

`orient` 不动写了 `angle` 的件、参考板复用的件和带插件脚的件（接口、排针、按键朝向按外壳和手定）；转了以后外框不能碰到原来没碰的器件。gen 输出里「自动定方向」列出转了哪些、飞线短了多少。

已经有的板子用 `easyedatool place` 整理（见命令参考）。

## `[schematic]` 原理图

```toml
[schematic]
layout = "pages"              # 默认：分页，芯片的附件连实线，避开标题栏，放不下自动加页
# layout = "build.py"         # 旧画法：一张图、每个引脚短线加网络标签（核对用）
# size = "A3"                 # 图框：A4（默认）或 A3（嘉立创的 A3 图框，标题栏在右下）
ground = ["GND", "GND_ISO"]   # 可选：地网络名单（不给就按名字认）
power = ["+3V3", "VIN"]       # 可选：电源网络名单
```

命令行 `gen --layout pages|build.py` 盖过这里。

- 一个芯片连同附件比一页还高（DDR 芯片挂着一长串去耦电容）时，两头都是电源 / 地的电容（去耦）不再挂在芯片脚上，改成单独排、两头用电源和地标志连；没超高的照旧挂在脚上。
- 只改原理图不动 PCB：`gen --schematic-only`（换图框、改排法后用，布好的线不丢）。

## JSON 写法

同样的结构，表名当键：`{"project": {...}, "board": {"outline": [[0,0],…]}, "parts": [{"ref": "U1", …}], …}`。
