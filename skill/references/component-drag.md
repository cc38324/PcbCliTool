# PCB 元件带线平移

窗口点「开始改」后拖动元件，或按 M 后放下。相连线端随焊盘移动，原有分支接点、固定过孔和其他器件焊盘留在原处；选中多个元件时可一起平移。拖动中的青色连线是示意，松手后由 Rust 规划实际路径、尝试推挤普通邻网走线并重算铺铜，成功后刷新板子。

放下时会把相连的无分支旧拐点一起放开，整理到焊盘、过孔、分支、线宽变化或锁定铜为止，优先尝试短的 45°/90° 路径，受阻才跑网格绕线。移动焊盘内的旧短线归并到焊盘中心；新连接处分支旁无接点、未锁定且不长于两倍线宽的旧线尾可剪掉。新线路及其与保留线的连接不允许形成小于 90° 的外露内角，连到原线中部的 T 接点也检查（原生坐标取整容差 0.2°）。固定接点和线宽不因整理而改变，受阻会拒绝，不能保证任意位置都能放下。

移动、相连线、被推开的邻网线和铺铜是同一步，Ctrl+Z 一次撤销，Ctrl+Y 重做。路径、连通、间距、完整丝印外框或项目质量规则不能通过时整次拒绝，保留原 PCB。拒绝后换个位置或先手工整理邻近走线。不会靠缩线宽、缩孔径或移动固定过孔让移动成功。

目前仅支持平移。旋转、翻面仍是原有摆放操作，不带线；涉及差分/等长约束的元件、锁定的相连铜线、圆弧或多点原生线路会拒绝带线平移。普通推挤无法保证任意拥挤位置都能移动。撤销保存整次 PCB 快照；外部重新生成或修改后快照不再匹配时拒绝覆盖。

接口先 `POST /api/edit/start`，再 `POST /api/edit/op`：

```json
{"op":"place","ref":"R3","at":[2.175,17.350],"angle":90,"bottom":false,"follow_tracks":true}
```

坐标毫米、Y 向上，`angle` 和 `bottom` 必须与现状一致。平移不写 `follow_tracks` 时默认带线；显式 `false` 使用原有只移动封装的操作，会留下断线，不能当成安全编辑。`many` 在最外层传 `follow_tracks`，内部所有操作必须为平移。成功 `undo_what` 包含「带线移动」「连线跟随，铺铜已更新」；失败返回 409 和 `error`，不新增历史。完成后 `POST /api/edit/done` 保存布局和铜，运行项目 `drc`、`check` 并检查局部截图。

工程 `easyedatool.toml` 的 `[checks].rules` 指定正式规则文件，编辑器同时保护规则中的禁止走线区域和布线质量要求。屏蔽罩实体、焊盘开窗到金属墙的装配净空仍需按机械模型单独核对，电气 DRC 不能代替这一项。

实际焊盘轮廓可用 `pads <工程> --json pads.json` 导出。`pads` 数组含位号、脚号、网络、层、毫米位置、角度、钻孔标记、阻焊扩展以及 `shapes` 的点列和半径；`source_sha256` 对应当前原生 PCB 字节。圆/胶囊用点列和半径，填充多边形用闭合轮廓和半径，外部机械检查应同时考虑阻焊扩展，不能只查元件本体包围盒。
