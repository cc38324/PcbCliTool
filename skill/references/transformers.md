# 开关电源变压器：参数、绕制与3D来源

把计算书、绕制规格书、PCB封装和3D对应到同一料号/版本。先区分选用成品变压器与磁芯、骨架加定制绕组两条路线。用户只问方法或来源时，先说明这些路线；实际计算时才补齐所需工况，不默认某个输入电压、功率、频率或磁芯。

## 先确定拓扑和工况

反激利用励磁储能，需联合确定励磁电感、峰值电流和气隙；正激、推挽和桥式需按相应激励与复位条件设计。LLC还需联合考虑谐振电感、励磁电感及变比，不能照搬反激公式。基础参考：[TI功率变压器设计](https://www.ti.com/lit/ml/slup126/slup126.pdf)、[TI电感与反激变压器设计](https://www.ti.com/lit/ml/slup127/slup127.pdf)。

| 输入项 | 应记录的内容 |
|--------|--------------|
| 拓扑与控制器 | 控制芯片完整型号、参考电路版本；反激DCM/CCM/准谐振等工作方式、占空比和限流约束。 |
| 输入 | AC/DC、最小/额定/最大输入；市电输入还需整流滤波后母线的谷值和峰值，不能把AC有效值直接代作绕组电压。 |
| 输出 | 每路电压、额定/峰值电流及同时负载关系、辅助绕组需求、总功率、效率目标。 |
| 开关波形 | 频率范围、最大导通时间、绕组实际电压和电流波形；变频和保护工况也要列入。 |
| 温度与机械 | 环境、允许热点/温升、散热条件、长宽高限值、立式/卧式安装及骨架针脚要求。 |
| 隔离 | 工作电压、所需绝缘等级及适用标准、爬电/电气间隙、耐压/绝缘测试条件；不统一填一个耐压值。 |

## 变压器参数清单

| 参数组 | 关键参数和用途 |
|--------|----------------|
| 磁芯 | 厂家及完整料号、EE/EER/EF/EFD/ETD/PQ/RM等形状、材料牌号、有效截面积`Ae`、磁路长度`le`、有效体积`Ve`、绕线窗口；外形相同不代表材料与损耗相同。 |
| 磁路 | 组装后的`AL`及公差、气隙位置与长度、励磁电感`Lm`；初级开路测得的`Lp`注明测法及漏感影响。说明是无气隙、集中气隙还是分布气隙。 |
| 匝数与变比 | 初级`Np`、各次级`Ns`、辅助`Na`；定义变比方向，例如`Np:Ns`，并记录起止脚、同名端和绕向。 |
| 电流与磁通 | 每绕组峰值和有效值电流、最大磁通密度`Bpk`和摆幅`ΔB`；按温度、输入、负载和控制限流检查。饱和上限和损耗允许摆幅分别判断。 |
| 线材与结构 | 裸铜径、绝缘后外径、并绕股数/利兹线规格、每层匝数、层数、绕制顺序、绝缘胶带与挡墙、屏蔽层及其接法。窗口占用包含绝缘，不能只加裸铜面积。 |
| 损耗与寄生 | 各绕组DCR及参考温度、交流铜损、磁芯损耗、漏感、需要时的绕组间电容；夹层绕法要同时权衡漏感、电容与隔离。 |
| 骨架及装配 | 骨架厂家料号、绕线尺寸、针数、保留/缺省针、脚距、排距、针径、伸出长度、离板高度、夹具和灌封/绕包后的外包络。 |

EE25、PQ26等尺寸系列不能单独确定多少瓦、多少匝或脚位。材料、频率、磁通摆幅、窗口利用和散热共同限制可用工况；初选尺寸后仍须复核绕得下及损耗温升。

计算时按控制器原厂的对应拓扑设计方法确定变比、`Lm`、电流和应力，再用磁芯/材料数据选择匝数与气隙，并迭代线材、填充、损耗。用`L = AL × N²`换算时，`AL`须对应实际组装气隙、材料和测试条件，核对nH/µH单位；小信号电感不能代替带直流偏置的饱和复核。

只在理想化DCM反激、励磁电流每周期从零开始并完全退磁时，可用`Pout ≈ η × ½ × Lm × Ipk² × fs`作初步能量核对；不把它用于CCM、LLC或其它拓扑。厂家推导示例：[ADI MAXREFDES1175](https://www.analog.com/en/resources/reference-designs/maxrefdes1175.html)。

## 用哪些设计工具

- [PI Expert](https://www.power.com/design-support/pi-expert)：用于其支持的Power Integrations器件和方案，可生成变压器构造报告、电气/机械图和绕制说明；先核对芯片支持情况，不当作任意控制器的通用求解器。
- [TDK Magnetic Design Tool](https://tools.tdk-electronics.tdk.com/mdt/index.php)：按所选磁芯和材料查询/计算磁性、损耗等数据；[帮助](https://tools.tdk-electronics.tdk.com/mdt/index.php/help_main)包含线损和非正弦磁通的磁芯损耗方法。磁芯损耗须记录材料、频率、波形、磁通和温度，不能把正弦曲线直接套到所有开关波形。
- 其它控制器按对应厂家设计指南、参考设计或计算表复核；[Ferroxcube材料资料](https://www.ferroxcube.com/en-global/download/index/material_brochure)可查材料特性。参考方案中的磁芯、气隙和绕组只适用于其原工况，换输入/输出不能直接沿用。

## 给绕制厂家什么资料

交付一张同版绕制规格书，至少把以下内容列清：

1. 磁芯、材料、骨架、气隙/目标`AL`和装配外形图。
2. 针脚编号观察方向（顶视/底视）、每绕组起止脚、同名端、匝数、线径/股数、绕向、层序和绝缘结构。
3. 初级电感及公差、变比/相位、各绕组DCR上限、漏感目标；分别注明测量频率、电压、温度和其它绕组开路/短接状态。
4. 设计峰值/有效值电流、温度限制、成品外形/脚位公差及项目要求的绝缘/耐压测试条件。

试制后用样品确认电感与漏感、相位、限流附近磁通/电流表现、温升及要求的绝缘测试；计算值、估算值和实测值分别记。外包络和电气参数通过后再固定库件版本。

| 对象和来源 | 获取及使用方法 |
|------------|----------------|
| [Würth开关电源变压器目录](https://www.we-online.com/en/components/products/pbs/power_magnetics/transformers_for_acdc_converter) | 成品料号下的Downloads可查STEP/IGES、WRL和EDA文件；例如`7508110333`所在条目有这些文件。根据实际料号下载，并核对电气规格和引脚图，不仅匹配EE/EFD外形。 |
| [Coilcraft功率变压器产品页示例A0009](https://www.coilcraft.com/en-us/products/transformers/power-transformers/power-converter-transformers/a0009/) | Resources有Datasheet及3D Model入口；按目标料号查询，实际文件、格式和下载条件逐项确认。 |
| [TDK磁芯及附件CAD说明](https://www.tdk-electronics.tdk.com/de/194476/tech-library/publikationen/ferrite/ferrite-air-gaps/2905808) | 该系列部分ETD/PQ/E磁芯及附件提供STEP。定制绕组时分别找配套磁芯与骨架完整料号的机械图/CAD；不把磁芯单件模型称为完整变压器。 |
| [TraceParts的变压器示例](https://www.traceparts.com/en/product/premo-sl-flyback-transformers-flyt003?Product=90-14052019-026877) | 可找到厂家提供的成品模型，例如PREMO FLYT-003，页面列有STEP/OBJ/STL等格式。它只是获取渠道示例，不表示适合当前电源。 |
| 实际骨架/变压器供应商 | 定制件索取骨架型号、针脚图和STEP。只有二维尺寸图时据图建模，尺寸不明的部分保留未核实记录；不按一个通用EE型号强配针脚。 |

磁芯形状、骨架和成品绕组外包络分别核对：同一磁芯可能配立式/卧式、不同针数或脚距的骨架；加胶带、绝缘挡墙、夹具后尺寸还会变化。PCB封装以实际骨架成品脚位图为准，确认编号观察方向、缺针、排距和焊脚尺寸；完整本体丝印与方向标记保留。

没有完整成品3D时，可以在外部CAD装配两片磁芯、骨架、绕包外廓、引脚及固定结构。无需逐匝建线来做占位预览，但须保留真实外包络、关键开口、针脚和离板高度，明确哪些是简化。用黑色贴图伪装穿孔会影响装配判断，不能替代实体孔。照片只辅助近似配色，不决定脚距、功率、匝数或绝缘等级。

## 本工具当前怎样接入

- `smps`检查开关电源版图/回路，不计算磁芯、匝数或绕制工艺。`thermal`的`transformer`项可按给定的每绕组`dcr`、`i_rms`及`p_core`估算损耗；DCR模型不含完整高频绕组损耗，缺少`p_core`时只算铜损。不能把该结果说成已完成磁件设计。现有字段见[规则格式](rules-format.md)。
- 完整磁件计算和试制报告作为独立设计资料保存；当前没有`transformer design`命令，也没有可直接写入设计/布线文件的磁芯/绕组参数表，不编造未实现命令或字段。
- 整板3D可绑定毫米OBJ或已有方块/圆柱参数配方；厂家STEP/IGES先经CAD转换，再按实际位号配置`easyedatool.toml`的`[view3d.parts."位号"] model`。`model3d`目前不支持任意复杂磁芯几何或布尔挖孔，步骤见[模型与焊盘说明](models-and-pads.md)。
- 下载链接、原始CAD、转换后的文件记录来源与版本；实际看模型与PCB叠加，核对外形、针脚、1脚方向、离板高度和正反面。模型只验证机械占位，不提供磁性、电气或绝缘性能结论。
